## 4. 三轮复核后确定的共同规则（拟议，执行前冻结）

### 4.1 数学与信息边界

对投影前固定的 q、x+、x−，令 β=||x−−q||²/||x+−q||²>1，ρ 为两个位移方向余弦。
Tri-Law 给出对独立高斯矩阵随机性的单点对反转概率 p(β,ρ,m)。
它不直接给出 P(真实近邻被 HNSW 漏掉 | 当前搜索现场)。

- 先由同一投影选点，再代入无条件规律，会引入选择效应；需要条件化理论或实际校准。
  搜索中所有检查共享投影，不能把每次检查当成独立试验或未经证明逐次花费 alpha。
- 精确 β、ρ 可能已经需要待省略的原空间计算。只允许它们进入离线诊断/教师标签；
  在线须使用已付费的状态、预存信息或实际计费的估计。不得把真值分支当部署分支。
- 若 T=f(β估计,ρ估计,m)，基线又拥有同样输入，T 没有增加观测信息；可能收益来自
  归纳偏置或有限样本效率。比较“间隔”“间隔+角度”“同输入+Tri”“同输入普通非线性”。
- 共用投影下的点对事件不能默认相互独立；不能用若干 (1−p) 的乘积认证整体召回。
- 原始向量归一化，平方 L2，Gaussian 元素方差1/m，无投影后归一化。最终规范
  float64 评分和稳定字符串 ID ties 不变。图内部 float32 决策另行记录，不能混同。
- 点对距离相等、零距离、非有限、边界数值不确定时不强行套 β>1 公式，保守精算/
  继续搜索，并保存无效计数。任何新数值判定规则须进入待批 L0 配置与测试。

- 保存实际候选/context集合、retention@10、Hit@5、每查询差值、低分位数和失败查询。

- 时间包括查询投影、特征、路由、访问、队列/缓存、补救、原空间精算、精排及分配。

## 5. 方案1：风险感知的 ANN 距离比较器

**问题：** 在不误删关键路径的前提下，能否少读/少算原空间候选距离？
潜在应用是 CPU 上高维、未高度量化的图检索；是否在384维就有效由实测决定。

### 5.1 先测现象和路径条件下的空间

1. 在原空间图的正常 base-layer 搜索中插桩，记录候选、pivot、所有相关队列阈值、
   ndis、结果/候选堆是否改变、访问顺序及高层成本；不改变排序或跳过节点。
2. 无决策改动的 no-op 版本先与 FAISS1.8.0原版逐查询检查返回候选、内部距离、规范重排。
   不匹配则该后端为 blocked，不能将 Python/C++ 重写的差异当作新策略收益。
3. 离线构造“当前距离计算不改变任一算法状态”的 oracle。不能仅以“不进入最终
   top10/64”为可省标签：一个暂时不进结果的节点仍可能进入 frontier、充当桥接点。
4. 原轨迹上计算可省完整距离数量和条件成本空间；单独测其同精度 SIMD 距离核、
   128维比较、查询投影、索引读取/查表成本。此步骤只是原路径的局部上界筛查，
   不是改变路径后的系统时延/召回结果，也不把全部 native time 都算成可省距离。

若原路径访问数V固定，完整距离费用cD，低维比较费用cm，精算比例r，必要条件为：

`V * ((1-r)*cD - cm) > T_feature + T_query_projection + delta_T_graph`。

384->128、按维度线性计费且其他费用为零时，需 r<2/3；该算式不保证真实节省，
尤其未计额外读写和实际路径变化。不能通过给原空间基线换慢距离核制造空间。

### 5.2 再测 Tri 是否提供额外价值

对照依次为：不跳过；低维距离间隔；单距离 chi-square 诊断/经验门控；间隔+廉价
角度估计；同输入的普通非线性模型；同输入+Tri变换。所有拟合/校准遵守第4节。
单距离检验在适应性筛选下也不默认有完整搜索保证。

- 离线 exact β/ρ + Tri 只用作机制诊断。在线输入限当前低维信息、已精算 pivot、
  已付费/预存边几何；β/ρ估计、角度、索引附加字节、查询预处理均计费。
- 初始小模型拟采用固定容量、L2正则的线性/逻辑模型及小表，避免大量模型搜索。
  正则/余量仅由开发角色确定；Tri不能享受更多参数或更多候选调参机会。
- 若在线 β估计不能严格定向或所需几何不可用，回退完整距离。Tri变换只作为
  可校准特征，不把估计参数代入后的数值称为精确后验风险。
- 报告误拒有用候选率、保留率、risk-coverage曲线、校准、有效/无效覆盖率，以及
  Δndis/Δbytes/特征时间；查询和边界间隔分层，不能只报平均预测误差。

### 5.3 最后才接真实搜索

正向信号出现后在独立 C++ 原型接过滤与有界暂缓队列；保留访问信息，不将暂缓节点
永久标成已处理。补救何时触发、队列上限和终止规则在 select 封存前确定并实际计费。
必须真正重跑修改后的路径；影子日志重放不能替代实际召回/时延。

退出条件：oracle空间不足；廉价规则已取得同样收益；Tri依赖完整待省距离；精度/
桥接丢失无法控制；或完整费用吞掉节省。保留普通 ANN 优化与“Tri无增量”可并存。
通过条件不是更低距离调用数，而是第4节的质量、完整成本和独立Tri增量共同有信号。

## 6. 方案2：保留现场的连续搜索控制

**问题：** 搜索到当前状态，再做一小段图扩展的收益是否值得成本？
潜在应用是难度差异大、固定ef对简单查询明显过搜的高召回工作负载。

### 6.1 构造可审核的连续轨迹

1. 第一版固定从一开始使用相同 beam capacity（参考256），只改变实际工作停止点。
   不在小ef已丢弃候选后扩堆并假装等价于大ef；不重复外部 `search(k)`。
2. 保留 frontier、visited、结果堆、距离缓存、未完成邻居位置和停止状态。
   no-op检查点在任意暂停/恢复组合后须与不中断原版输出一致；否则先停止该路线。
3. 拟检查点累计 ndis 为128/256/512/1024/2048以及原版自然终点；只有足够结果时
   才可停止。不打断批量距离核，在下一合法边界暂停并记录实际超额工作。

   `ΔHit`、新增实际访问/距离成本，不进入线上动作。

### 6.2 免费空间、廉价控制、Tri消融

先在上述同一连续轨迹上求质量约束停止 oracle，并比较固定ndis、标准完整搜索、
查询无关混合、距离gap/停滞规则。自然终点也不能免除基础成本或恢复已错过近邻。
oracle只覆盖这一束宽/路径的停止动作，不宣称所有路径的收益上限。

若空间足够，拟合三组：廉价状态（ndis、更新数、当前距离/分位数、frontier gap）；
同状态加几何；同输入加Tri。主目标为继续动作的边际收益/成本，校准后再决定
停止或继续；预测整体retention作辅助，不把预测好看当作加速。

Tri仅在预定检查点计算，最多16个按固定规则选择的当前已精算点对；查询投影和
角度成本支付，禁止读未来frontier或真值。 terminal不支付无用特征。廉价状态
即能确定动作时允许门控跳过Tri；蒸馏只作为后续另记的消融，不预先假定成功。

距离驱动停止和 DARTH式状态控制属于机制对照；在未移植论文完整实现之前，不写
“超过DARTH/Ada-ef”。原空间搜索本身不需要投影，因此 Tri 在此只是辅助几何信号，
对未访问区域难度的关联须实测，不能由点对公式推出。

退出条件：真实续搜oracle也没有明显空间；Tri检查费用高于可省工作；廉价状态
已覆盖收益；或质量恶化。若只证明了连续搜索有价值而Tri无增量，分开保留结论。

## 7. 方案3：第二个独立投影视角的选择性补救

**问题：** 对少数查询追加另一独立视角，是否比加深第一视角更划算？
潜在应用是允许额外索引内存、需要高召回且投影损失明显互补的查询尾部。

### 7.1 先验证互补性，分清两类损失

先做100k：原空间图、两个独立 Gaussian128 视图各建一个新索引。除种子/坐标外，
构图参数、顺序、线程与资源预算相同；两个矩阵都在观察新结果前固定，不筛种子。

1. 使用两视图各自**精确投影** top64/128，以及相应图实际返回集合，原空间精排。
   精确扫描只用于质量归因，其计时不能冒充 ANN 查询时延。
2. 保存每查询投影漏失、图额外漏失、图偶然补回，以及两个视图的漏失交集/候选交集。
   使用集合恒等式归因，不把两种误差简单相加；保存精度/边界ties影响。
3. 比较同视图更深搜索/更大返回池、固定两视图union、随机/廉价门控、免费按需
   第二视图 oracle。单视图分配同总ndis/时间预算，也比较单视图128与双视图各64；
   原空间 ANN 全成本和内存始终在表中。union较大带来的收益不能独归多视角。
4. oracle主模型在**第一视图费用已经支付后**选择是否补救；额外投影、第二图访问、
   去重、融合、原空间新增距离均计入。免费搜索前选视图只能作更乐观诊断。

### 7.2 理论对照必须正确

固定q/x+/x−、两个独立高斯矩阵：同一对在两视图都反转的概率是p1*p2。
这不是把点对p换名成ANN漏检率。若完整两个搜索过程在固定语料/查询条件下确实
仅依赖各自独立随机性，可另外分析完整漏失事件；其边际概率仍非Tri点对p。

部署两个矩阵已经固定，且查询难度异质，跨查询的平均联合漏失不能通过两平均率
相乘得到。第二视图预算若由第一视图结果选择，还须按实际门控动作分析。
同一矩阵取负、复用相同随机行或只改图种子均不是独立投影视角。

### 7.3 有互补性才训练触发器

如果oracle相对同成本单视图深搜和查询无关混合仍有空间，才比较廉价首轮状态与
同状态+Tri 的“第二轮Δquality/Δcost”触发器。只能读第一轮已算状态。
同ID的原空间精算共享，cache lookup、候选融合和暂存字节实际计费。

每个100k矩阵/索引固定一次；若结果依赖这一个种子组合，只记特例可行性。后续
多种子或1M验证需另记范围和预算，不能在报告集上换种子重试。双索引是显式内存
和构建代价，报告性能—质量—内存三维取舍，不将额外内存换来的收益都归给Tri。

退出条件：投影漏失不互补；图搜索吞掉互补；单视图加深更优；oracle仍不敌原空间
ANN；或第二索引成本不适合应用。初筛止于100k也须保留完整真实负结果。

然后独立执行`candidates.push`；`MinimaxHeap::push`还有自己的容量/距离条件。
因此“进不了结果top64”不足以跳过该点，必须同时检查对frontier/停止状态的影响。

已批准的独立native原型采用以下接口和约束；旧安装库/旧实验入口保持不变：

```text
normal graph expansion produces neighbor x
    h = cheap_observations(q, x, evaluated_reference, queue_state)
    action = RiskDistanceComparator.inspect(h)  # ExactNow / Defer / Unavailable
    if action == Unavailable: action = ExactNow
    if action == ExactNow:
        compute full original distance; update normal result/frontier queues
    else:
        keep x in separate pending state; do not invent an exact heap distance
at checkpoints / before stopping:
    apply the frozen pending-audit and rescue rule; pay all its work
```

初始运行是shadow模式：照常精算/更新，只记录规则会做的动作。no-op对照通过后
才允许真实Defer。近似分数不进入需要完整距离的主堆；暂缓不等于永久visited。
全部pending补算可能吞掉所有收益；有限补算又不能保证不漏点，必须实测这一取舍，
不能用“有回退队列”代替召回验证。[FINGER](https://arxiv.org/html/2206.11408v1)
和[PAG](https://arxiv.org/html/2603.06660v1)支持这种精算/路由分离的工程方向，
不提供本原型所需的Tri条件化或最终召回保证。

### 12.3 无需训练的Tri派生对照：能直接得到什么

以下是由现有Tri-Law推导的**固定点对上界**，不是新增已部署算法或完整ANN定理。
令q、x、z在抽取Gaussian投影前固定，0<||x-q||<=||z-q||，即x不比参考点z远。
对t>1，定义S=||Π(x-q)||²/||Π(z-q)||²。则

`P(S >= t) <= F_sf(t; m,m)`。

推导：令a=x-q、b=z-q、β=||b||²/||a||²>=1。S>=t等价于人工点对
(a,sqrt(t)*b)的反转；其原距离平方比是tβ>1。由Tri-Law及ρ=0最坏情况，
该概率<=F_sf(tβ;m,m)<=F_sf(t;m,m)。连续性使严格/非严格事件概率相等；
共线情况概率为0，零距离需单独保守处理。

因此可以先研究固定表格`t_alpha=F_isf(alpha;m,m)`的无训练比较器，不必先训练
adapter。m=128时，公式例子为：

| 固定点对alpha | 平方投影距离比阈值t_alpha |
|---|---:|
| .05 | 1.338908446070 |
| .01 | 1.512107243527 |
| .001 | 1.734579111262 |

本次用SciPy F分布及未修改的`tri_law_probability`核对了尾概率，并对tβ取β=1/1.1/2、
ρ=0/.5/.9/1的边界示例检查上界；未做新的Monte Carlo、检索或拟合。

适用限制必须保留：这是已固定几何下、对重新抽取投影的错误概率，不是
`P(x仍有用 | 已观察S、当前frontier)`；不能在适应性搜索中直接赋予每次alpha保证。
在已选投影、已选参考点、反复检查和native float32几何下，需要额外处理。
最坏ρ被消除后主要剩距离比信息，可能不优于单距离chi-square规则；二者都须测。
如果只有这个保守版本可成立且无收益，应停止，而不是预设学习可以修复。

### 12.4 角度感知Tri如何避免先支付待省距离

一种明确的低成本几何入口是扩展pivot u到邻居x的边：

- A=||u-q||²已在搜索中计算；C=||x-u||²可在离线边元数据中预存。
- B=||x-q||²正是希望避免的完整距离，先用低维距离取得估计B_hat。
- 对有效估计，rho_hat=(A+B_hat-C)/(2*sqrt(A*B_hat))，
  beta_hat=max(A,B_hat)/min(A,B_hat)>1；输入现有Tri函数得到局部不稳定度特征。

它只需单次低维候选距离、边元数据读取及标量运算；查询投影、边存储/预计算和
已有距离的精度处理都要计费。估计不构成有效三角形、beta无法严格定向或几何
无效时回退精算，不能随意clip成自信风险。native已算距离也不等同实数真值。

但这里得到的是(q,u,x)的**估计反转敏感度**，不是x相对结果/前沿边界点z的精确
误跳过风险。u不一定是边界z；如果改用z，C=||x-z||²通常不再是现成图边长度。
不得再算一次完整x-z距离却称免费。可以研究低维角度估计，但额外内积必须计费。

因此实际规则需要同时读入当前各队列的margin，将Tri作为可解释特征或保守校准
信号；只按p<某阈值永久剪枝不成立。先做固定规则/查表和同输入廉价对照，再决定
是否需要学习`P(会误跳过有用节点 | 可观测状态)`。精确规律、估计特征、校准风险
是不同对象，不能靠adapter命名把缺失推理链省掉。

### 12.5 三路线的算法前置与学习的地位

| 路线 | 先做的算法改动/无训练对照 | 学习何时才有意义 |
|---|---|---|
| 1 | native精算前比较、pending与审核；固定距离规则及Tri派生表 | 可观测风险与可省计算确有关系，而简单规则不足时 |
| 2 | 完整session暂停/恢复；固定工作量和距离gap停止；离线oracle | 已证实存在可省后续工作，才预测继续一段的收益/成本；点对Tri本身不认证停止 |
| 3 | 独立索引、候选去重/共享精算、固定补救规则与补救oracle | 已证实第二视角互补且经济，才学习触发；p1*p2不是部署查询的完整漏检率 |

先明确动作与必要信息，再无训练规则验证，再做有/无Tri和有/无学习消融。
算法本身没有有效信息或成本空间时，不进入adapter训练。旧五文件范围已包含这些
native/配置/测试改动；若今后要改变图构建准则、投影家族或旧scientific模块，则
另列精确路径/目的，不能从本次确认推导任意核心改动批准。
