**1．一个研究问题、一个概率对象**

研究问题：

> 固定一个严格最近邻和有限竞争点集，在一次共同iid Gaussian投影下，哪些低阶联合信息能把最近邻掉出投影top-M的概率限定到有用范围？若不能，能否给出Gaussian可实现的不可辨识界？

先固定k=1。令q、x_0、x_1…x_n在投影前确定，a=x_0−q，b_j=x_j−q，并要求0<||a||<||b_j||。候选池与待分析矩阵独立，矩阵Pi的元素独立服从N(0,1/m)。定义：

```text
I_j = 1{ ||Pi*b_j||² < ||Pi*a||² }
Z   = sum_{j=1}^n I_j
theta(G;m,M) = P_Pi(Z >= M),  1 <= M <= n
G = Gram(a,b_1,...,b_n)
```

在目标—竞争者没有投影距离并列的条件下，目标的投影排名恰为1+Z；因此遗漏事件与Z>=M严格等价。严格原距离、投影零测并列、退化/重复情况由T1逐项证明或显式分支处理，不能靠浮点epsilon修改事件。

这里的随机性只来自重新抽取Pi。查询和语料都是固定几何；不把同一Pi内的n个竞争者当独立样本。首轮不讨论固定部署矩阵对未知query的泛化，也不将theta称为整套ANN的漏召回概率。

原向量归一化用于面向embedding的子结论，不能与一般欧氏几何混写。投影后不归一化，始终按平方L2排序。k>1、外部候选生成及图遍历全部延后；T4前不得通过扩大目标来替代未解问题。

| 信息层级 | 保留什么 | 能用于什么、不能推出什么 |

| S_struct | S_1及明确结构类、相关性/块结构限制 | 可研究该类内的保证；不能外推任意几何 |
| S_G | 完整G | 决定共同Gaussian投影的联合规律；准备和计算都可能昂贵 |

同一摘要下，令A(S)为满足PSD、维数、严格最近邻及声明归一化条件的可实现Gram集合，定义：

```text
L(S) = inf_{G in A(S)} theta(G;m,M)
U(S) = sup_{G in A(S)} theta(G;m,M)
W(S) = U(S)-L(S)
```

W衡量摘要的不可辨识范围。两个可实现几何提供的是W的下界，通常不是其精确极值。若要宣称匹配极值/锐界，必须同时给出全类上界与达到或逼近它的构造。

任意Bernoulli分布的可行集合通常比Gaussian几何生成的指示分布更大。对前者求出的紧界可作为后者的保守界；不能因此声称对Gaussian类也紧。任意相关矩阵/任意Bernoulli反例也不能直接当作可实现Gaussian排名反例。

**4．候选理论命题：先有可复核基准，再尝试一个增量**

以下是T1–T3待核对、证明或否证的工作条目，不是本文件已经冻结或执行的新算法。

**4.1 完整Gram参考与可实现性。** 令V=[a,b_1,...,b_n]，G=V^T V。Pi V的m行独立且各服从N(0,G/m)，因此 projected Gram 具有对应的、可能奇异的Wishart表征。这一推导应独立写出，并用“原空间抽Pi”和“由G直接生成行”两条实现对照。因子化必须允许真实低秩；不许加jitter把不合法PSD几何悄悄修成另一个问题。

构造一族保持S_1的几何可从：

```text
a = e_0
b_j = sqrt(beta_j) * (rho_j*e_0 + sqrt(1-rho_j²)*u_j)
u_j perpendicular e_0, ||u_j||=1
R_jl = u_j dot u_l, R PSD, diag(R)=1
```

入手。变化只发生在残差Gram R，beta_j>1与rho_j保持。维数至少支持rank(R)+1；相同m、M和目标距离尺度下比较theta。首轮只取独立残差、近共线、预声明的分块三类，不做无限制几何搜索直到出现正结果。

**4.2 单位球落地。** 不要逐点归一化旧反例来声称保持边际。可先核对以下几何条件：若V由位移列组成、c_j=−||v_j||²/2，则要同时满足||q||=||q+v_j||=1，需要V^T q=c及||q||=1。检查c是否在G的值域、最小范数解及正交补维数。非退化有限构造可尝试对全部位移统一缩放，再平移到单位球；必须证明其保持距离比/角度与投影排序事件。退化构造不一定允许这种提升。

这是归一化适用性检查，不预设为可发表新命题。若做不到，结论明确限定一般欧氏空间。

**4.3 可解的条件基准。** 写b_j=alpha_j*a+r_j，其中r_j⊥a。若所有非零r_j两两正交，则条件于w=Pi*a，各Pi*r_j相互独立且独立于w。T1需核对条件反转概率可写为非中心chi-square CDF：

```text
A = ||a||², s_j = ||r_j||²
T = m*||Pi*a||²/A ~ chi_square(m)
p_j(t) = CDF_noncentral_chi_square(
             A*t/s_j; df=m, noncentrality=alpha_j²*A*t/s_j)
theta = E_T[ PoissonBinomialTail(p_1(T),...,p_n(T); threshold=M) ]
```

该表达拟通过条件Gaussian推导、非中心参数核对、动态规划及一维积分交叉验证。s_j=0时单独处理，不能除零。它保留共享近点造成的依赖；先积分条件尾部，不能把边际p_j直接送入独立Poisson-binomial冒充同一结果。

这是一项候选可解参考，不预设具有新颖性。应查多元gamma/chi-square、条件独立混合及相关二次型文献；即使正确，也可能只是已有结果在当前记号下的特例。

**4.4 唯一优先增量。** 在T0审计后，优先研究：从条件独立残差基准出发，对显式受限的残差相关结构，能否给出比一般分布比较更有信息的排名尾部区间，或证明所选低阶摘要仍留有不可忽略的W(S)。在一个命题卡中固定几何类、摘要、m/n/M范围与目标界，之后不更换算法接口或追增结构假设。

“一个摘要不足”的负命题需要Gaussian可实现构造，最好覆盖单位球子类；“一个摘要足够”的正命题必须给出明确条件、误差量与计算要求。一般不能保证存在少量标量就足以描述任意几何。

**5．必须击败或解释的基线**

| 基线 | 信息输入与作用 | 必须防止的误报 |
|---|---|---|
| Markov | 仅mu | 合法但可能很松；不是唯一应比较对象 |
| 独立Poisson-binomial | 全部p_j | 作为有意失配的诊断；共同Pi下无普适保证 |
| Cantelli＋Markov取小 | mu和真实Var(Z)，M>mu时适用Cantelli | 连续距离差的协方差不等于反转指示协方差 |
| 计数矩LP | mu、nu及Z∈{0,...,n} | 对计数分布的紧界不等于Gaussian可实现紧界 |
| 小n Bernoulli状态LP | 各p_j与指定p_jl，变量为2^n个状态概率 | n受限；估计输入的不确定性不能忽略 |
| 已有树边际概率界 | 一元概率和树上两两边际 | 这是经典对照，既不新，也不要求真实分布满足树条件独立 |
| 条件基准/完整Gram数值参考 | 明确结构/完整G | 更完整信息带来的改善不能全部归因某新公式 |

计数矩LP在pi_z>=0、sum pi_z=1、sum z*pi_z=mu、sum z(z−1)*pi_z=nu下，对sum_{z>=M}pi_z求最大/最小。若用于上界声明，需检查对偶多项式在所有整数z=0…n上均覆盖事件指示，并保存数值/有理证书；浮点求解器返回success不是形式证明。

nu=2*sum_{j<l}p_jl。若这些输入由Monte Carlo估计，应使用同时有效的区间扩大可行集；不得把点估计插入后声称严格概率界。精确输入、数值积分误差和统计输入三个版本分开标注。

比较时区分“更多信息的价值”和“同信息更强算法的价值”。加入S_2后优于S_mu，不等于优于已有S_2概率界；也不等于该信息可在线低成本获得。
